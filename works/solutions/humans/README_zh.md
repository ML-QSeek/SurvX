# SurvX\-humans

## Overview \| 概述

**From constraints, cognition grows\.**

**约束生认知，存续生智慧。**

SurvX 是一套**约束驱动、无监督、自生长**的智能体生存与认知框架。

区别于传统大模型的概率拟合、强化学习的奖励最大化逻辑，SurvX 不依赖外部标签、人工奖励函数与预设最优解。智能体仅在客观规则与多重约束的边界中，通过持续的环境交互、因果归纳、行为试错，从零自主生长出适配生存的认知与决策体系。

**SurvX\-humans** 是 SurvX 通用范式落地于人类主体的延伸研究项目，将人类视作现实约束场中的高阶生存智能体，用「存续优先、因果自驱」的全新范式，重构对人类认知、决策、行为与成长的底层建模逻辑。

## Core Philosophy \| 核心理念

### Why SurvX \| 创作初衷

本项目的核心驱动力，源于对生命与智慧底层原理的本质探索：

**一个无预设导师、无外部奖励引导的主体，如何仅凭与环境的交互，自主演化出自适应的认知与生存行为？**

传统人工智能的核心目标是**最优解、收益最大化、损失最小化**，而 SurvX 的核心目标截然不同：

**在多重约束条件下，维持系统长期稳定存续，避免崩溃。**

我们不追求瞬间最优，只追求长期可持续；不依赖外部赋值的价值判断，只忠于客观环境的因果与后果。

### Core Positioning \| 核心定位

- **驱动逻辑**：约束驱动、后果驱动，而非奖励驱动、指令驱动

- **核心目标**：长期存续 \> 局部最优

- **认知来源**：纯内生生长，从交互经历中归纳因果，无外部灌输

- **运行特征**：无中心控制大脑，分层自治、动态迭代、可回溯

## Architecture \| 核心架构

SurvX 彻底拆分**世界规则（Field）**与**主体认知（S\-Ego）**两套完全隔离的运行系统，解耦环境规则与智能决策逻辑。

### 1\. Field ｜ 只读约束场（世界规则）

Field 是客观、静态、只读的环境底层规则，对智能体完全透明、无引导性：

- 定义实体属性、生存边界、底层物理/客观法则

- 仅对主体行为返回**真实客观后果**，不解释、不打分、不建议、不纠错

- 独立运行，修改规则无需改动认知逻辑

在 **SurvX\-humans** 中，Field 即**现实世界**：包含物理规则、生理极限、时间资源、社会规则、生存资源等所有人类必须遵守的客观约束。

### 2\. S\-Ego ｜ 自生长认知系统（主体心智）

S\-Ego 是动态迭代、版本可回溯的内生认知系统，是主体生存决策的核心，核心能力为**因果归纳与未来推演**：

- 记录每一次「行为\-后果」交互数据，沉淀真实因果关系网络

- 归纳影响因子、作用方向与影响程度，合并同类经验

- 面对新场景，基于因果网络推演多套行为方案

- 筛除违规、高风险、会导致系统崩溃的方案，择优执行

### 3\. 三层认知自治架构

无统一中央大脑，三层分层联动、自主调节、逐层升维：

- **本能层**：基于生理、情绪、生存反馈的即时响应，负责基础避险与生存应激

- **认知层**：核心决策层，完成因果归纳、未来推演，修正本能层的短视、冲动行为

- **符号层**：语言、概念、叙事能力随认知生长自然生成，完全本地内生，无预设符号库

## Core Closed\-Loop \| 核心运行闭环

系统每时间单位（tick）循环执行，认知持续迭代生长：

**经历交互 → 因果归并 → 方案推演 → 行动验证 → 状态更新**

1. **经历交互**：主体在 Field 约束中执行行为，获取客观后果

2. **因果归并**：S\-Ego 沉淀经验，更新因果关系网络

3. **方案推演**：基于现有认知，预判不同行为的未来结果

4. **行动验证**：筛选可持续、低崩溃风险的方案落地执行

5. **状态更新**：带入新状态进入下一轮循环，认知持续进化

## SurvX vs 传统智能范式

|维度|传统 AI / RL|SurvX \(humans\)|
|---|---|---|
|驱动方式|奖励函数、标签监督、概率拟合|客观约束、行为后果、因果自驱|
|优化目标|收益最大化、损失最小化、最优解|长期存续、系统稳定、规避崩溃|
|认知来源|外部数据训练、人工预设规则|环境交互内生生长、自主归纳|
|运行逻辑|被动拟合、被动优化|主动推演、主动试错、主动适配约束|
|适用场景|任务专项最优解|复杂约束下的长期生存与成长|
