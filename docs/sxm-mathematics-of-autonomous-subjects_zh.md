# SXM：自治主体的数学

本文暂不展开具体公式，首要任务是提出研究问题、划定边界、确立方法、给出验证方案。公式属于后续工作，当前先完整建立问题空间。

## 一、研究问题

自我意识、个体行为、群体效应这类现象已被长期研究，但始终缺少一套统一的数学工具。

“一个主体如何行为、如何认知、如何演化”的相关思想散落在心理学、行为学、博弈论、控制论、复杂系统等领域，尚未形成统一且可操作的内核。

本文目标，是为该类现象建立一个可供研究的数学问题空间。

## 二、研究方法

采用功能主义，搁置本体层面讨论。

仅遵循这一方法论：从功能出发，考察对象“做什么”，而不去追问“它本质是什么”。

意识带来的神秘感，很大程度并非源于内在机制，而是感知获取方式：只能通过第一人称向内感知，无法直接共享、无法公开核验，但可以交流。因此从功能与行为切入，是唯一可公开验证的路径。

这套方法论决定后续所有取舍：凡是无法从功能上验证的内容，不纳入框架。

## 三、理论内核

一组核心变量 + 两种角色 + 反馈环路。

核心变量为一组包含内在状态的变量。

同一组核心变量同时承担双重角色：

1. 被维护对象：存在存续约束，一旦跌破危险区间，主体失效；
2. 行为驱动源：变量存在缺口时，驱动主体产生行为。

存续（维持自身存在）和驱动（产生目标诉求）并非两套独立事物，而是同一组核心变量的两种作用。

缺口 → 驱动行为；跌破底线 → 存续失效。

反馈环路分为内外两支：

对内：读取自身状态
对外：改变外部环境

二者形成闭环；主体行为就是该闭环持续求解得到的结果。

因此最小内核可概括为：

一组核心变量 + 维持/驱动双重角色 + 一套反馈环路。

## 四、系统性质

本文刻画的系统，是带有反馈、目标权重动态可变、多目标共存、约束随时间变化的耦合非线性系统。

由此可推得：

- 绝大多数场景下不存在简洁解析解；
- 在稳定环境中，可以求得可行解、近似最优解；
- 真实环境开放且动态，不存在全局最优，只有持续适配的可行解。

所以这套数学框架并不追求“最优”，而是追求“可行”。

它描述的不是“如何求解一个优化问题”，而是“一个主体如何在开放环境中持续适配、维持存续”。

## 五、认知机制

个体认知不等同于真实环境。

环境对于个体而言是未知的；个体拥有自身内在认知。

个体求解得到的“最优”，是基于自身认知的最优，不等于真实环境下的全局最优。

认知与环境之间的偏差，驱动认知持续更新。

可分为利用与探索两种模式：

- 不主动更新认知：在已有认知下得到近似最优解；
- 主动认知探索：将“缩小认知偏差”纳入目标集合，新增探索目标，此时全局最优不再成立。

这意味着，在这套数学框架里，“最优”是不稳定概念，随认知、探索行为发生变化。能够求解的，只有当下认知条件下的可行解。

## 六、验证方案

本框架属于可实验体系，并非纯粹演绎思辨。

验证方式：回测，思路类似量化投资，将主体置入环境中仿真运行。

效果评判包含长期表现、短期表现两个维度。

核心观测指标：生存曲线，刻画主体沿时间轴的存续表现。

可拓展研究方向：

- 如何使个体更好、更有目标性地生长；
- 环境设计（教育、治理、舆论导向等）；
- 从个体演化推导群体行为。

验证方式约束框架形态：

模型必须支持仿真、回测；
变量必须可观测、可计算；
否则无法绘制生存曲线。

## 七、研究边界

研究对象需要同时满足：

持续维护一组核心内部变量；
处于多重约束环境；
存在多个相互冲突的目标；
具备对内感知、对外行动能力，形成闭环反馈；
行为是这套系统持续动态求解的结果。

体系边界：

框架仅定义单个自治个体的行为与认知生长规则；种群、代际演化属于延伸方向，不是研究起点。

属于纯数学规则体系，不绑定生物、机器、仿真载体，可以通用刻画所有自治系统。

不给出本体论结论，只坚守功能主义方法论。

## 八、纲领定位

本文不提供最终答案，而是搭建问题空间：

界定哪些问题值得研究、采用何种方法、如何判定研究成功、划定不在研究范围内的内容。

体系最终简单或复杂，交由后续研究回答；现阶段目标是让这套自治主体的研究问题可研究、可验证、可推进。

## 九、数学形式

### 9.1 主体

主体在环境中演化，其结构、自我认知、机制三者随时间变化。

主体由以下要素构成：

- 结构 M：主体的组织形态；
- 自我认知 E：主体对自身与环境的内部模型；
- 机制 Φ：主体内部的关系与函数（即 Q 的抽象）；
- 核心变量 C：一组被维护、同时驱动行为的变量。

主体结构随时间的更新规则为：

M_{t+1} = F( M_t , E_t , Φ_t ; C_t )

自我认知随时间的更新规则为：

E_{t+1} = G( E_t , M_t ; C_t )

其中 F、G 为更新规则，C_t 为核心变量在 t 时刻的取值。

环境 V 是主体演化的背景，不作为与主体并列的独立项，而是作为上述更新的条件出现。

环境自身随时间变化：

V_{t+1} = H( V_t , M_t , E_t )

### 9.2 外部标准

外部标准由研究者给定，作用于主体的发展轨迹，输出匹配度：

S : {M_t} → 匹配度

分为两类：

- 有限目标：S({M_t}) = 距离(M_T, S)
- 无限目标：S({M_t}) = 沿时间累积的 M_t 变动率匹配度

### 9.3 顶层问题

给定外部标准 S，求配置，使主体轨迹 {M_t} 与 S 的匹配度最大：

max Match( {M_t}, S )

约束：

- 自洽约束：所有行为必须在自我认知 E 内自洽；
- 存续约束：核心变量 C 中作为被维护对象的变量，不得跌破危险区。

### 9.4 核心变量的位置

核心变量 C 是主体的支点：

- 它作为被维护对象，进入存续约束；
- 它作为行为驱动源，进入更新规则 F、G；
- 它的缺口驱动行为，它的底线决定失效。

机制 Φ 不单列，内嵌在 F、G 中，表现为函数关系。
