# Contributing to SurvX

Welcome to contribute code, ideas, and improvements to SurvX! 🎉

This project is currently in an **early stage**; guidelines are kept simple, practical, and actionable.

## How to Contribute
- Report bugs
- Suggest features and design improvements
- Improve documentation
- Submit fixes and small module enhancements

## Issue Guidelines
- Search existing issues first to avoid duplicates
- For bugs: describe the issue + steps to reproduce
- For features: explain use case and value
- For large changes: open an issue for discussion first

## PR Guidelines
- Create a feature branch from `main`
- Keep changes small and clear for easy review
- Describe what you changed and why
- Large architectural changes require prior discussion

## Commit Convention (Simple)
Keep commit messages clear, e.g.:
- `feat: add xxx module`
- `fix: correct xxx logic`
- `docs: improve xxx`

## Current Stage Note
The project is under early iteration; architecture and paradigm are stabilizing.
Contributions follow **lightweight, clear, and practical** principles, not over-specification.

Thanks for your support!
